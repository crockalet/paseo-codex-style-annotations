# Codex Style Annotations

[English](README.md) | [简体中文](README.zh-CN.md)

在 Paseo 的聊天、文件编辑器、Markdown 预览、Diff 或终端中选中文字，将其作为注释添加到对话，再按需补充评论。已保存的注释可以编辑，也可以在原文仍可定位时跳转回去。

`v0.2.0` 在聊天注释的基础上新增工作区来源和注释类型设置。

## 安装

需要 Paseo 0.11.4 或更高版本，并支持原生插件设置。先在「设置 > 插件」中启用插件。若已安装原版 `quote` 插件，请先停用。

```bash
paseo plugin disable quote
paseo plugin add git:xzthemeofsss/paseo-codex-style-annotations --ref v0.2.0
```

以上命令安装 `v0.2.0`。没有安装 `quote` 时，跳过停用命令。运行时 ID 保持为 `quote-notes`；原版插件保存的注释仍可读取，编辑时保留其身份信息。

## 添加和编辑

选中文字后点击「添加到对话」。工作区来源会显示「添加到 {对话名称} 对话」，默认使用同一工作区最近聚焦的聊天，点击箭头可切换接收者。即使没有打开输入框，也能添加到对应草稿。

注释立即出现，评论可以留空或稍后补充。添加注释不会发送消息，发送仍使用 Paseo 的正常输入框。

新建评论时，Enter、Esc 或离开输入框会保存当前文字，Shift+Enter 换行，输入法组词不会确认评论。

悬停或聚焦注释数量胶囊可查看摘要，点击可固定展开。通过「编辑」或原文编号进入编辑卡片。在卡片中，Enter 换行；点击「保存」或按 Cmd+Enter（其他平台为 Ctrl+Enter）提交修改。点击「取消」、按 Esc 或点击外部会放弃尚未提交的编辑。垃圾桶按钮删除该条注释。

保存或删除结果未确认时，请先处理错误，再重载或停用插件。重试文字只保存在内存中；关闭卡片不会撤销已经尝试提交的操作。

点击摘要条目可返回来源。原文位置失效时，已保存的文字仍可读取，草稿注释仍可编辑或移除。

## 来源开关和语言

在「设置 > 插件 > Codex Style Annotations > 注释类型」中，分别开关聊天、文件、Diff、Markdown 和终端注释。默认全部开启。设置属于对应主机上的插件安装，只影响新注释；已有注释和聊天侧边提问仍可使用。

插件启动时读取设置，每次添加前再次检查。读取失败和保存冲突会显示错误，不会重置已保存的值。

设置、选区工具栏和侧边提问编辑框跟随 Paseo 的中英文设置，其他语言回退到英文。部分注释弹窗目前仍显示中文。

## 来源和定位限制

| 来源 | 保存内容与限制 |
| --- | --- |
| 聊天 | 渲染后的选文和宿主提供的 Markdown。 |
| 文件编辑器 | 一段连续文字、文件路径、行号和文档指纹。只有内容一致时才精确高亮，包括未保存的修改。 |
| Markdown 预览 | 渲染后的文字和文件路径，不推算源码行号。 |
| Diff | 单个文件、单侧的连续选区，支持左右布局和统一布局。拒绝混合文件、混合侧、区块标题和不连续范围。重开时不保证原行位置；工作区比较引用会变化。 |
| 终端 | 选文、终端会话、缓冲区类型及坐标。后续输出、缩放、关闭或重载可能使精确定位失效。 |

采集不会使用剪贴板或向终端发送输入。目前不支持网页内容注释，也不支持从工作区来源发起侧边提问。过长的定位元数据可能被拒绝。

## 已发送注释和侧边提问

点击已发送的注释胶囊，或按 Enter、Space，可展开完整文字并复制。Esc 关闭预览并恢复焦点。已发送注释为只读；由于 Paseo 发送后不再单独保存评论元数据，展开视图保留包含评论的完整文字。

通过校验的待确认消息会在确认前后保留同一个胶囊。不支持的消息，以及原生适配器尚未就绪时的消息，会保留原生附件样式。

对聊天选区使用「在侧边聊天中提问」会创建子 Agent，沿用主对话的供应商、模型、模式和思考档位，并携带选文、可获取的来源消息，以及最多八轮近期主对话。可在侧栏继续提问，也可打开为普通聊天标签。

## 数据和兼容性

插件以受信任代码运行，读取选区、来源上下文、同工作区的 Agent 与草稿、已发送附件、注释设置，以及侧边提问需要的近期对话。注释保存在 Paseo 原生草稿中；发送草稿或侧边提问时，内容通过配置的模型供应商发送。只有主动复制条目时才写入剪贴板。

适配器会检查应用私有接口，并从同源读取 Paseo 自身的 JavaScript 包。Paseo 升级后可能需要适配更新。插件不添加外部后端，也不在运行时安装软件。停用插件会恢复原生附件卡片，并保留已保存的注释。

聊天界面已在 macOS Paseo 0.11.4 上检查。针对已安装 0.12.0-beta.3 渲染器的隔离浏览器验证覆盖了工作区采集、明暗工具栏、窄窗口、语言切换和待确认消息胶囊。这些验证不代表所有运行中的客户端均已确认。完整浏览器客户端和移动端尚未独立验证，移动端使用系统选区菜单。

## 开发和许可

```bash
npm ci --ignore-scripts
npm run typecheck
npm test
```

保留的测试读取本机安装的 Paseo 原生模块，可通过 `PASEO_BUNDLE` 指定其他应用包。测试不会安装插件或向 Agent 发送消息。
